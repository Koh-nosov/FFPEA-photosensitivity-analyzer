# FFPEA
**FFmpeg Photosensitivity Epilepsy Analyzer**  
_Инструмент открытого для проверки видео на риски фотосенситивных приступов._

FFPEA — это лёгкое, быстрое и полностью автономное веб-приложение, которое помогает видеомонтажёрам, режиссёрам и геймдизайнерам проверять свои материалы на соответствие медицинским рекомендациям по фоточувствительности (тест Хардинга / PEAT).

## Почему горошек?
Это простая и запоминающаяся метафора:
- **FF** — это сердце приложения, библиотека FFmpeg. Мы используем её, скомпилированную в WebAssembly, чтобы выполнять всю тяжёлую работу прямо в браузере.
- **PEA** — Photosensitivity Epilepsy Analyzer. Мы наследуем идеи классического инструмента PEAT, но делаем его доступным в вебе.
- **Pea** — в переводе с английского означает «горошина». Мы хотели подчеркнуть, что инструмент компактный, универсальный и «круглый» в хорошем смысле — подходит для любых видео.

## Возможности
- Полностью работает на стороне клиента. Видео не покидает ваш компьютер — обработка идёт в браузере через WebAssembly. Безопасно и конфиденциально.
- Интерактивный график рисков, который строится в реальном времени. Спокойные участки подсвечиваются мягким зелёным, а опасные — красным.
- Умный таймлайн: клик по любому месту дорожки мгновенно перематывает плеер на этот кадр. Можно быстро перейти к подозрительным пикам.
- Продуманный интерфейс в тёмной монохромной гамме, с поддержкой системной темы, плавными переходами и двумя языками (русский и английский).

## Запуск локально
Если хотите развернуть проект у себя для разработки или офлайн-тестов:

1. Скачайте или склонируйте репозиторий.
2. Запустите встроенный Python-сервер (он настроит необходимые заголовки COOP/COEP для работы ffmpeg.wasm):
   ```bash
   python server.py
   ```
3. Откройте в браузере адрес `http://localhost:8000`.
